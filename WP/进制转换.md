### 进制转换

#### 一、思路

 HTML 实体编码（`&#56;`），解码后是一堆混杂了十进制、八进制、十六进制的数字字面量，每个数字对应一个 ASCII 字符，拼接字符得到flag

```
  HTML 数字实体
  html.unescape 解码
  将得到的含3种进制的字符串
  转成 ASCII 字符
  拼出明文
```
