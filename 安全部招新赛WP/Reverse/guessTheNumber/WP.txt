直接找140001014函数，看伪代码，发现这是一个验证函数
a1 == 51966才会执行该函数，而程序里根本就没有调用这个函数
donotuse.png
只需要读懂它的算法，然后逆向

v2 = aH0wT03ncrypt[14 - i % 0xF] ^ *(_BYTE *)(i + a2); //发现^异或加密代码

aH0wT03ncrypt代表"H0w_t0_3ncrypt?"
'0xF'字符串长度15，刚刚好就是"H0w_t0_3ncrypt?"的长度
"i % 15"给i循环取模，[14 - i % 0xF]把"H0w_t0_3ncrypt?"从后面往前取
"*(_BYTE *)(i + a2) — a2"是输入字符串的指针，a2 + i就是第i个字符，取一个字节的值，也就是a2[i]
可以看出来H0w_t0_3ncrypt?倒转后直接参与了XOR的运算

140001040函数接收一个字符串，XOR加密后和hex字符串比较
根据hex = flag XOR key
就有flag = hex XOR key


写py脚本逆向异或，得到flag
enc = bytes.fromhex("7821352D093A1B6C39011A3B2844200C2B024A335231706F5E002D1801174C00021C130E13")
key = b"H0w_t0_3ncrypt?"[::-1]  #伪代码里下标是14 - i % 15，即从字符串末尾往前取字符，等价于把字符串反转后循环使用
flag = bytes([enc[i] ^ key[i % 15] for i in range(37)])
print(flag.decode())
