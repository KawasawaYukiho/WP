## RSA 原理

RSA 是一种非对称加密，分公钥和私钥两把钥匙

###### 1. 生成密钥

选两个大素数 p、q：

```
n = p × q
φ(n) = (p-1)(q-1)
```

选一个小奇数 e（通常 65537），求它的逆元 d：

```
d = e⁻¹ mod φ(n)   # 即 (e×d) % φ(n) == 1
```

- **公钥** = (e, n)，公开
- **私钥** = (d, n)，保密

###### 2. 加密

别人给你发消息 m，用公钥 e 加密：

```
c = m^e mod n
```

###### 3. 解密

你收到密文 c，用私钥 d 解密：

```
m = c^d mod n
```

数学上 `(m^e)^d ≡ m (mod n)`，所以加解密能互逆。

### 4. 为什么安全

想从公钥 (e, n) 算出私钥 d，必须先分解 n 得到 p 和 q，才能算 φ(n)。但 n 是几百位的大整数，**分解它非常慢**（几百年），所以安全。

### 5. 这道题为什么被攻破

正常情况下 n 分解不了，但这道题给了两个 n1、n2，它们共用了同一个 p：

```
n1 = p × q1
n2 = p × q2
```

gcd (n1, n2) 直接把 p 求出来了，n1 就分解了，φ(n1) 能算了，d 也就暴露了。

**一句话：RSA 的安全靠 "大整数难分解"，共享素数让分解变得容易，所以崩了。**
