
运维实习生在一次例行检查中，交给我们一台 Linux 机器的口令文件 `shadow`，以及它的一份旧备份 `shadow.bak`。

据实习生介绍，该系统使用一套“自研”的口令哈希方案。文件每行格式为：

    用户名:$id$salt$hash

- `$id$` 表示所使用的哈希算法，这里 `7` 表示 SHA256-crypt
- `salt` 为十六进制随机数，每行单独存放
- `hash` 为算法对盐值和口令作用的结果
- 口令字段为单个 `!` 的行表示账户已锁定

已知 SHA256-crypt 的算法为：

    hash = SHA256(salt + password)

即把盐值与口令直接拼接后做一轮 SHA-256，输出小写十六进制。
