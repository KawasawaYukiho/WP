### 深夜广播

#### 一、思路

```
需要不同尝试才能发现散布的flag
缺定位符二维码修复解码，得到flag第1段
值班室照片.jpg 提取尾部附加数据, 提取 flag 第2段
神秘音频.wav看频谱图得到flag第3段
拼接得到flag
```

#### 二、分析过程

##### 2.1 损坏的二维码.png
二维码无法直接识别，用工具添加定位符后，识别出
```
flag{ye_ban_
```
即 flag 的前半段为 `ye_ban_`。

##### 2.2 值班电脑室里的照片.jpg

用十六进制编辑器打开 JPG，滚动到文件末尾，发现 JPG 结束标记`FF D9`后还有一段数据

<img src="images/深夜广播/jpg_hex.png" alt="JPG尾部附加数据">

```
guang_bo_
```

##### 2.3 神秘音频.wav

音频听不出内容，用 Audacity打开频谱图观察，在频谱中可以看到明文字符

<img src="images\深夜广播\spectrogram.png" alt="神秘音频信息" width="200">

```
xin_hao}
```

#### 三、最终 Flag
3段进行拼接，得到flag
```
flag{ye_ban_guang_bo_xin_hao}
```
