============================================================
  安网阁招新赛 WP —— 动态调试（Click Counter）
  附件：dynamicdebugging.exe
============================================================

【题目描述】
用 IDA 动态调试，找到程序中的 flag。

【程序分析】
这是一个 Windows GUI 程序（Click Counter Challenge），
界面上有一个 "Click Me!" 按钮，需要点击 100000 次才能拿到 flag。
正常点根本点不完，所以需要动态调试跳过计数。


【详细操作步骤】

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
步骤 1：用 IDA 打开 dynamicdebugging.exe
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 打开 IDA Pro，拖入 dynamicdebugging.exe
2. 加载 PE 文件，等待分析完成
3. 按 F5 看伪 C 代码


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
步骤 2：找到关键逻辑
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

在伪代码中找到按钮点击处理函数，核心逻辑类似：

  count++;                          // 每次点击 +1
  if (count >= 100000) {           // 点满 10 万次
      MessageBoxA(hWnd, "Flag Found!", ...);   // 弹窗显示 flag
  } else {
      wsprintf(buf, "Progress: %d/100000 (%.1f%%)", count, ...);
      SetWindowTextA(hStatic, buf);          // 更新进度显示
  }

关键变量就是 count（点击计数器）。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
步骤 3：切换动态调试器
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 菜单栏：Debugger → Select debugger → Local Windows debugger
2. 点击绿色三角形（Start process）或按 F9 启动
3. 弹出警告框点 Yes
4. 程序启动后会弹出一个 GUI 窗口（Click Counter）


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
步骤 4：在计数判断处下断点
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

方法 A（推荐）：在 if (count >= 100000) 处下断点
1. 在伪代码中找到比较 count 和 100000 的那一行
2. 光标移到该行，按 F2 下断点（变红）
3. 回到 GUI 窗口，随便点几下 "Click Me!" 按钮
4. 程序会断在这个断点上

方法 B：直接在 MessageBoxA 调用处下断点
1. 在伪代码中找到 MessageBoxA 的调用
2. 按 F2 下断点
3. 但需要 count >= 100000 才会走到这里，所以要用方法 C


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
步骤 5：修改计数器值（关键！）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

断下后：

1. 在反汇编窗口中找到 count 变量所在的内存地址
   （通常在栈上，类似 [ebp-4] 或 [ebp-8]）

2. 在栈窗口（Stack window）中找到 count 的值
   当前应该是你点了几下的数字（比如 3、5、10）

3. 右键点击该地址 → Edit（或按 Ctrl+E）
4. 把值改成 0x186A0（即十进制 100000）
5. 按 F9 继续运行
6. 程序会直接走到 MessageBox，弹出 "Flag Found!" 窗口


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
步骤 6：另一种方法——直接跳过判断
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 断在 count++ 之后的比较指令处
2. 反汇编中会看到类似：
     cmp [ebp-4], 186A0h
     jl short loc_xxxxxx       ; 如果小于 100000 就跳走
3. 把 jl（小于则跳）改成 nop，或者直接改 EIP 跳到 MessageBox 调用处
4. 按 F9 继续


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
步骤 7：快捷键速查
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  F9          继续运行
  F7          单步步入（进入函数）
  F8          单步步过（不进入函数）
  F4          执行到光标处
  F2          添加/删除断点
  Ctrl+E      编辑内存/寄存器值
  Ctrl+F7     执行到返回


【最终 Flag】
------------------------------------------------------------
CTF{H4ck3r_Th1s_Is_F0n}
------------------------------------------------------------

（直接 strings 提取也能看到，但题目要求用动态调试——
 核心思路就是下断点 → 找到计数器 → 改成 100000 → 继续运行）


【为什么要动态调试】
- 正常需要点 10 万次，物理上不可能完成
- 动态调试可以直接修改内存中的计数器值
- 这是逆向中最常见的套路：找到校验点 → 改值/跳过判断
