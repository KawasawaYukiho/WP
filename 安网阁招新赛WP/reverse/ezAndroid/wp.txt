反编译后核心代码（Kotlin 等价）：

  class MainActivity : AppCompatActivity() {
      companion object {
          // 38 个 int，存储了加密后的数据
          val CIPHER = intArrayOf(
              0x3ee, 0x3e4, 0x3e9, 0x3ef, 0x3f3, 0x3e2, 0x3e9, 0x3ec,
              0x3f0, 0x3d7, 0x3fa, 0x3bb, 0x3fe, 0x3bb, 0x3fa, 0x3fb,
              0x3b9, 0x3e6, 0x3ef, 0x3d7, 0x3e5, 0x3bc, 0x3fb, 0x3fc,
              0x3bb, 0x3fa, 0x3d7, 0x3b8, 0x3fa, 0x3d7, 0x3bc, 0x3e6,
              0x3ec, 0x3fa, 0x3b8, 0x3b9, 0x3ec, 0x3f5
          )
      }

      fun check(input: String): Boolean {
          // 第一步：长度必须等于 38
          if (input.length != CIPHER.size) return false

          // 第二步：逐字符 XOR 校验
          for (i in input.indices) {
              if ((input[i].code xor 904) != CIPHER[i]) {
                  return false
              }
          }
          return true
      }
  }

关键发现：
  - 校验算法很简单：input[i] XOR 904 == CIPHER[i]
  - 反过来就是：input[i] = CIPHER[i] XOR 904
  - 密钥是固定的 904（0x388）

  cipher = [
      0x3ee, 0x3e4, 0x3e9, 0x3ef, 0x3f3, 0x3e2, 0x3e9, 0x3ec,
      0x3f0, 0x3d7, 0x3fa, 0x3bb, 0x3fe, 0x3bb, 0x3fa, 0x3fb,
      0x3b9, 0x3e6, 0x3ef, 0x3d7, 0x3e5, 0x3bc, 0x3fb, 0x3fc,

      0x3ec, 0x3fa, 0x3b8, 0x3b9, 0x3ec, 0x3f5
  ]
  key = 904  # 0x388
  flag = ''.join(chr(c ^ key) for c in cipher)
  print(flag)

输出：flag{jadx_r3v3rs1ng_m4st3r_0r_4ndr01d}

【考点总结】
- jadx 反编译 APK，定位 MainActivity
- 分析 check() 方法的校验逻辑
- 发现 XOR 加密，密钥 904
- 反推：CIPHER[i] XOR 904 = 原始字符
- 不需要运行 APP，纯静态分析即可拿到 flag
