### 不可逆的加密

#### 一、思路

```
x 用整除把字符"加密"成整数
奇数字符：c = (5n+3)//3
偶数字符：c = (5n+2)//4
整除 // 是一对多，但 flag 字符都是可打印 ASCII
直接枚举 32~126 键 密文转字符 反查表
```

#### 二、分析过程

##### 2.1 加密函数

```python
def encrypt(n):
    if n % 2 == 1:            # 奇数字符
        return (5 * n + 3) // 3
    else:                     # 偶数字符
        return (5 * n + 2) // 4
```

用了整除，多个 n 可能映射到同一个 c，正向不可逆
flag 只含可打印字符

##### 2.2 反查

```python
enc = [128, 135, 162, 172, 206, 60, 125, 125, ...]

table = {}
for n in range(32, 127):
    table[encrypt(n)] = n

flag = "".join(chr(table[c]) for c in enc)
```
